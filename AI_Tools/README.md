# AI_Tools

Everything in this folder was generated by an AI assistant. **Nothing here is server code.**

The project keeps AI-generated material physically separate from the Lineage 2 server itself, so
that the server tree stays exactly what it claims to be: source, config, datapack, and client files.

## The rule

> Anything an AI writes that is **not** server code goes under `AI_Tools/`.

Server code, configs, datapack files and client files stay where they belong — in `Server/`,
`Deployemnt/`, and `Client/`. They are never mixed with the material here.

## Layout

| Folder | Contents |
|---|---|
| `scripts/` | AI-written helpers that generate, edit, migrate or inspect project files — `.ps1`, `.sh`, `.py`. Tools *about* the project, never part of the running server. |
| `docs/` | AI-written Markdown — architecture notes, reviews, requirements, design documents, prompts. |

## The one exception

`CLAUDE.md` lives at the **repository root**, not in `docs/`.

This is deliberate. Claude Code only auto-loads that file from the root of the repository; filing it
here would mean future sessions start with no project context at all, which defeats its purpose.
It is the only AI-authored Markdown file allowed outside this folder.

## Provenance

Documents here record what was true when they were written. Before acting on one, check that the
paths, table names and file references it cites still exist — the server tree moves, and these notes
do not update themselves.
